# Blazor Server DataGrid - EditTemplate with TimePicker

## Overview

This sample demonstrates how to customize editing within a Syncfusion [Blazor DataGrid](https://www.syncfusion.com/blazor-components/blazor-datagrid) by rendering a TimePicker control inside an EditTemplate. Instead of relying on the default editor generated by the grid, the implementation uses a dedicated TimePicker editor for time-based fields during record editing. When users save their changes, the selected time value is updated in the underlying data source. This approach is useful for applications that require accurate and consistent time entry while maintaining an intuitive editing experience.

## Key Features

- Demonstrates DataGrid editing through a custom EditTemplate implementation.
- Renders a Syncfusion TimePicker control within the grid EditForm.
- Replaces the default editor for a time-based field with a specialized TimePicker editor.
- Updates the bound data source when edited values are saved.
- Shows integration between Syncfusion DataGrid editing infrastructure and a TimePicker component.

## Prerequisites

* [.NET SDK 10.0](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) or later
* [Visual Studio 2026](https://visualstudio.microsoft.com/downloads/) or [Visual Studio Code](https://code.visualstudio.com/)

## How to run the project

**Visual Studio 2026**:

* Checkout this project to a location in your disk.
* Open the project (`GridEditTemplateWithTimePicker.csproj`) file.
* Restore the NuGet packages.
* Run the project.

**Visual Studio Code**:

* Checkout this project to a location in your disk.
* Open the repository folder in Visual Studio Code.
* Open the integrated terminal.
* Navigate to the repository root.

```bash
cd EJ2-DataGrid-BlazorServer-GridEdit-EditTemplate-TimePicker
dotnet restore
dotnet run
```

Open the URL displayed in the terminal after the application starts.
